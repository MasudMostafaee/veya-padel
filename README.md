# Veya Padel Club

A concept website for a fictional padel club, built from a low-fidelity wireframe as a teaching example. Veya is not a real club.

Built with Astro, GSAP and Lenis.

```bash
npm install
npm run dev
npm test
```

- Copy and prices: `src/content/*.json`
- Sections: `src/components/`
- Motion: `src/scripts/`
- Photo credits: `CREDITS.md`

`_to-delete/` holds the old wireframe files and can be removed.
